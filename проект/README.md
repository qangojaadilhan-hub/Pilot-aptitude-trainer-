# Pilot Aptitude Trainer ✈️

A small browser-based aptitude trainer inspired by common pilot-selection practice areas.

## Features
- Numerical sequence questions
- Mental arithmetic
- Logical pattern questions
- Randomized questions
- Score calculation
- Simple responsive interface for phone and desktop

## How to use

No installation is required.

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Answer the questions and view your score.

## Technologies

- HTML5
- CSS3
- JavaScript

## Purpose

This project was created as a small educational programming project for practicing numerical reasoning and logical thinking.
